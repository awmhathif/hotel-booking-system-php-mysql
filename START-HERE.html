Before you start

Get your computer ready

Goal: by the end of this chapter, XAMPP and VS Code are installed and you have an empty project folder.

You don't need to know programming to start. This chapter installs two free programs and checks they work. It takes about 20 minutes, most of it waiting for downloads.

What you are going to build

A booking website for a small hotel. It has two kinds of users:

  • Guests look at rooms, search by dates, make an account, send a booking request, see and cancel their bookings, print an invoice and send the hotel a message.
  • The admin (the hotel) sees today's arrivals and departures, confirms or rejects requests, gives each booking a real room number, checks guests in and out, saves payments, manages room types and rooms, and replies to messages.

A booking moves through clear stages: waiting (the guest asked) → confirmed (the hotel said yes and gave a room) → in the hotel → checked out. It can also be rejected by the hotel or cancelled by the guest.

You build it in 12 steps. After every step the site works and you can open it in the browser. If a step goes wrong, the steps folder in this package has the full project as it should look after every step (steps/step-01 to steps/step-03), so you can copy that and carry on.

The finished project is about 1,350 lines of PHP, 450 lines of CSS and 50 lines of JavaScript, spread over 12 steps. Each step adds between 70 and 260 lines.

The 4 things the site is made of

Part What it does Where you see it
HTML The content: headings, text, forms, buttons Inside .php files
CSS How it looks: colours, spacing, sizes css/style.css
PHP The logic: check a form, save a booking, decide who can see a page Inside .php files, between <?php and ?>
MySQL The database: the tables that keep rooms, users and bookings phpMyAdmin

There is also a small JavaScript file, js/app.js (3 short parts: an "Are you sure?" box, live search in a table, and the live price on the booking form). Every page also works without it.

When you open a page, this happens: your browser asks for rooms.php → Apache (the web server) gives the file to PHP → PHP asks MySQL for the rooms → PHP builds the HTML → the browser shows it.

XAMPP puts Apache, PHP and MySQL on your own computer, so you don't need the internet or a hosting account.

1. Install XAMPP

  1. Go to apachefriends.org and download XAMPP for your system (Windows, Mac or Linux).
  2. Pick a version with PHP 8.2 or newer. This project uses a PHP feature (execute_query) that older versions don't have.
  3. Run the installer. Keep the default choices. On Windows it installs to C:\xampp.
  4. If Windows asks about the firewall for Apache, click Allow.

2. Start Apache and MySQL

  1. Open the XAMPP Control Panel (Windows: Start menu → XAMPP Control Panel. Mac: Applications → XAMPP → manager-osx).
  2. Click Start next to Apache. Then click Start next to MySQL.
  3. Both names turn green.
  4. Open your browser and go to http://localhost. You should see the XAMPP welcome page.

If Apache doesn't turn green

Another program is using port 80. On Windows this is usually "World Wide Web Publishing Service" (IIS) or Skype.

  • Fix 1: press the Windows key, type services, open it, find World Wide Web Publishing Service, click Stop, and set Startup type to Disabled.
  • Fix 2: in XAMPP, Apache row → Config → httpd.conf. Find the line Listen 80 and change it to Listen 8080. Save, start Apache again, and from now on use http://localhost:8080/hotel/ instead of http://localhost/hotel/.

More fixes are in guides/common-errors.md.

If MySQL doesn't turn green, or says "shutdown unexpectedly"

Another MySQL is already running on port 3306, or XAMPP's database files got damaged when the PC turned off suddenly. The exact fix for both is in guides/common-errors.md → "MySQL shutdown unexpectedly". Don't delete the mysql\data folder.

3. Install VS Code

VS Code is the editor where you write the code. It is free.

  1. Go to code.visualstudio.com, download it and install it.
  2. Open VS Code. Go to File → Auto Save and tick it. Now every change is saved by itself.

4. Make the project folder

  1. Open the folder C:\xampp\htdocs (Mac: /Applications/XAMPP/htdocs). Everything inside htdocs can be opened in the browser through http://localhost/.
  2. Make a new folder inside it called hotel (small letters, no spaces).
  3. In VS Code: File → Open Folder → choose htdocs\hotel → Select Folder. If it asks "Do you trust the authors", click Yes.

The left side of VS Code (the Explorer) now shows your empty HOTEL folder. This is where you will make every file.

How to make a file in VS Code

Hover over the HOTEL folder name on the left and click the small New File icon (a page with a +). Type the name, for example index.php, and press Enter.

To make a file inside a folder, type the folder name too: includes/header.php makes the includes folder and the file in one go.

How to use the code in this guide

Every code box has the file name on top and a Copy button.

  • New lines are marked with a black bar on the left and a bold line number. Grey lines were already in the file from an earlier step. The top of the box says which lines are new.
  • Removed lines are listed under the box when a step deletes or replaces something.
  • A long line wraps onto the next row inside the box. It is still one line in the file (it has only one line number).
  • The box always shows the whole file. If you typed the earlier steps, add only the marked lines. If you get lost, click Copy, click inside the file in VS Code, press Ctrl+A (select all), then Ctrl+V (paste). Mac: Cmd instead of Ctrl.

Type the code yourself. It is slower than pasting, but it is the only way you will remember it, and at your viva you will be asked to explain and change it. Read the explanation under each box before you type.

The database

You make the database once, in step 2, in phpMyAdmin (http://localhost/phpmyadmin). After that, when a step adds a table, the guide shows only the new SQL. You run it in the SQL tab and also add it to the end of your database.sql file, so the file always holds the whole database.

Words you will see a lot

Word Meaning
Variable A named box that holds a value. In PHP it starts with $: $price = 85;
Function A named set of instructions you can run again and again: e($text)
Array A list of values: $errors = ["name" => "Enter your name"];
String Text, written inside quotes: "Halden Hotel"

Step 2

Rooms from the database

Goal: the room types live in a MySQL table, the home page lists them as cards, and each card opens its own room page.

Until now the page only had fixed text. From this step on, PHP reads the data from MySQL, so the admin can change rooms later without touching the code.

1. Make the database

  1. Open http://localhost/phpmyadmin.
  2. Click New on the left. Type hotel_db as the name, choose utf8mb4_general_ci in the second box, and click Create.
  3. Click hotel_db on the left, then open the SQL tab.
  4. Paste the SQL below and press Go.
SQL to run in phpMyAdmin
1-- Hotel booking system database.
2-- In phpMyAdmin: create a database called hotel_db, open it, then run this file in the SQL tab.
3-- Each table is followed by its demo data.
4
5-- 1. Room types: what a guest books (Classic Double, Family Room...)
6CREATE TABLE room_types (
7 id INT AUTO_INCREMENT PRIMARY KEY,
8 name VARCHAR(60) NOT NULL UNIQUE,
9 description TEXT NOT NULL,
10 price DECIMAL(8, 2) NOT NULL,
11 max_guests INT NOT NULL,
12 photo VARCHAR(100) NOT NULL
13);

Also make a file database.sql in your hotel folder and paste the same SQL into it. That file is your copy of the whole database. Later steps add to the end of it.

  • CREATE TABLE room_types makes a table. Each line inside is a column: its name, its type and its rules.
  • id INT AUTO_INCREMENT PRIMARY KEY: every row gets a number by itself (1, 2, 3...). It is the row's unique key.
  • VARCHAR(60) is short text up to 60 characters. TEXT is long text. DECIMAL(8, 2) is a number with 2 decimals, right for money (never use FLOAT for money; it rounds badly).
  • NOT NULL means the column must have a value. UNIQUE means no two rows may have the same value.
  • Room types and rooms are two tables. A guest books a type ("Classic Double"); the hotel has several real rooms of that type (103, 104, 105). room_type_id in rooms stores which type a room is. FOREIGN KEY ... REFERENCES room_types(id) makes MySQL refuse a room whose type doesn't exist.
  • INSERT INTO ... VALUES adds the demo rows.

2. Connect to MySQL

Make includes/db.php:

hotel/includes/db.phpNew file
1<?php
2session_start();
3
4// Hotel details shown on every page
5define("HOTEL_NAME", "Halden Hotel");
6define("HOTEL_ADDRESS", "12 Lake Road, Halden");
7define("HOTEL_PHONE", "+1 555 0100");
8
9// Connect to MySQL (XAMPP: user root, no password)
10$conn = new mysqli("localhost", "root", "", "hotel_db");
11$conn->set_charset("utf8mb4");
12
13// Today's date from MySQL, so PHP and MySQL agree on the date
14$today = $conn->query("SELECT CURDATE()")->fetch_row()[0];
  • session_start() lets PHP remember a visitor between pages. You need it from step 3 on; it must run before anything is printed, so it is the first line.
  • define("HOTEL_NAME", ...) makes a constant: a value that never changes while the page runs. Constants have no $.
  • new mysqli("localhost", "root", "", "hotel_db") connects: server, user, password (empty on XAMPP), database.
  • set_charset("utf8mb4") makes names with any letters (é, ü, Tamil, Sinhala) save correctly.
  • $today asks MySQL for today's date. Later steps compare booking dates with it. Taking it from MySQL means PHP and MySQL always agree on the date.

3. Helper functions

Make includes/functions.php:

hotel/includes/functions.phpNew file
1<?php
2// Small functions used on many pages.
3
4// ===== Showing things =====
5
6// Makes text safe to put in HTML (stops people adding their own HTML or scripts)
7function e($text)
8{
9 return htmlspecialchars((string) $text, ENT_QUOTES, "UTF-8");
10}
11
12function money($amount)
13{
14 return "$" . number_format((float) $amount, 2);
15}
16
17// plural(1, "night") = "1 night", plural(3, "night") = "3 nights"
18function plural($count, $word)
19{
20 return $count . " " . $word . ($count == 1 ? "" : "s");
21}
  • e() is the most important function in the project. Whatever a user typed may contain HTML, for example <script>. htmlspecialchars turns < into &lt;, so the browser shows the text instead of running it. Every value from the database or a form goes through e() before it is printed. Forgetting it is a security hole called XSS.
  • money(95) gives $95.00. number_format adds the 2 decimals.
  • plural(1, "guest") gives "1 guest" and plural(3, "guest") gives "3 guests".

5. The room page

Make room.php:

hotel/room.phpNew file
1<?php
2require "includes/db.php";
3require "includes/functions.php";
4
5$id = (int) ($_GET["id"] ?? 0);
6$type = $conn->execute_query("SELECT * FROM room_types WHERE id = ?", [$id])->fetch_assoc();
7if (!$type) {
8 exit("That room doesn't exist. <a href='index.php'>Back to the home page</a>");
9}
10
11$pageTitle = $type["name"];
12
13require "includes/header.php";
14?>
15
16<div class="room-page">
17 <img class="room-photo" src="images/rooms/<?php echo e($type["photo"]); ?>" alt="<?php echo e($type["name"]); ?>">
18
19 <div>
20 <h1><?php echo e($type["name"]); ?></h1>
21 <p><?php echo e($type["description"]); ?></p>
22 <p><strong><?php echo money($type["price"]); ?></strong> a night · up to <?php echo plural($type["max_guests"], "guest"); ?></p>
23 </div>
24</div>
25
26<?php require "includes/footer.php"; ?>
  • $_GET["id"] is the id=3 part of the address. ?? 0 gives 0 if it is missing, and (int) turns it into a whole number, so text like 3abc becomes 3.
  • execute_query("SELECT * FROM room_types WHERE id = ?", [$id]) is a prepared query: the ? is a placeholder and the value is sent separately. MySQL never mixes the value into the SQL text, so nobody can change your query by typing SQL into the address. This stops SQL injection. Every query with a value from outside uses ? in this project.
  • fetch_assoc() gives one row, or null if there is none. A wrong id shows a clear message instead of an error.

  • go("contact.php") sends the browser to another page (header("Location: ...")) and stops this one (exit).
  • flash() saves a one-time message in the session; take_flash() reads it and deletes it. So "Message sent" shows once, on the next page, and not again after a reload.
  • Why the hidden code (CSRF). Another website could hide a form that posts to your site, and the browser would send it as you. This attack is called CSRF. csrf_field() puts a random code (random_bytes) in every form and remembers it in the session. check_csrf() refuses any form that comes back without the same code. Another site can't know it. hash_equals() compares the two safely.

One page, two jobs. When you open it, the browser asks with GET and the page shows the empty form. When you press the button, the browser sends the form with POST to the same page. if ($_SERVER["REQUEST_METHOD"] === "POST") runs the saving part only for POST.

  1. check_csrf() first. Nothing else runs if the code is wrong.
  2. $_POST["email"] is what was typed in the box with name="email". trim() removes spaces at the start and end.
  3. Every box is checked and each problem goes into $errors, keyed by the box name. All problems show at once, each under its own box.
  4. filter_var($email, FILTER_VALIDATE_EMAIL) is PHP's built-in email check. strlen() counts the characters.
  5. if (!$errors): no problems, so save with a prepared INSERT, set a flash message and go() back to the page. Sending the browser to a new page after saving is called Post/Redirect/Get: if the user presses refresh, the form isn't sent twice.
  6. If there are errors, the page carries on and shows the form again with the errors. value="<?php echo e($name); ?>" puts back what the visitor typed, so they don't have to type it again.

required and type="email" make the browser check the boxes too, but PHP must check anyway: anyone can switch browser checks off.
