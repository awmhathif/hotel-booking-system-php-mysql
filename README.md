# Hotel Booking System in PHP and MySQL: free starter

A hotel booking website. Guests see the rooms, send booking requests and follow them. The hotel admin confirms each request, gives it a real room and refuses double bookings.

This repository is the **free starter** of a step by step coursework kit. It is written for diploma, HND and degree students who need a PHP and MySQL project and want to understand every part of it. No coding experience is assumed.

## What is in this free starter

| File | What it is |
|---|---|
| [START-HERE.html](START-HERE.html) | Install XAMPP and VS Code, then build the first 3 of the 12 steps. The site works after every step. |
| `steps/step-01` to `steps/step-03` | The project exactly as it should be after each step |
| [guides/common-errors.md](guides/common-errors.md) | The real XAMPP, PHP and MySQL errors and how to fix them |
| [viva-sample.html](viva-sample.html) | 10 viva questions with answers and a practice mode |

Read the guide online: https://awmhathif.github.io/hotel-booking-system-php-mysql/START-HERE.html

## How to start

1. Download this repository (green **Code** button, then **Download ZIP**) and unzip it.
2. Open `START-HERE.html` in your browser. It works offline.
3. Follow step 0 to install XAMPP, then build steps 1 to 3.

Needs Windows, Mac or Linux with XAMPP (PHP 8.2 or newer). All software used is free.
